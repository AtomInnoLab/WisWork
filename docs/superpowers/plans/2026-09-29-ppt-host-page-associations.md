# 计划页与宿主页面关联

按原方案项目持久恢复与 BuildReceipt/稳定页身份要求，复用导入回执和替换、撤销覆盖。

1. 文档绑定枚举当前有效回执，应用已有替换覆盖及撤销恢复，排除已被取代的映射；返回副本，损坏拒绝。
2. 根据 production checkpoint 的精确 pageIds 与完成的 Slide ID 建立页级关联；当前 Office.js 快照核对存在性。关联多个副本、历史修订、未知修订、缺失页和未决导入分别表示；没有 pageIds 的旧整稿记录不按标题或页序猜测。
3. 工作台刷新只读关联，并核对文档、取消和读取期间回执变化。宿主读取失败保留项目，但明确关联不可用。展示默认折叠，不从页面存在推断当前内容或 QA。
4. 验证替换/撤销、重开、文档切换、取消及实际 HostRuntime 的 Office.js 快照接线，执行全量回归和构建。

本轮关联用于后续宿主写入保护的基础。仍须补精确源产物证明及宿主覆盖锁定页的提交前确认与校验；不能将只读展示当作完整覆盖保护。
