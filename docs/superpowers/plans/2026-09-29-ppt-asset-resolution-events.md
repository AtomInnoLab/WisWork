# PPT 素材生产解析事件实施计划

依据原方案 §7.1 和 O1；不修改原方案及退出标准。

1. 为实际逐页生产中的图片解析建立独立有界事件契约，保持旧页任务协议兼容。
2. 原子保存事件，绑定文档、项目、请求、冻结输入与计划摘要、页面、素材和尝试；隔离损坏记录。
3. 在真实解析前记录 fetching，在素材字节就绪后记录 ready，失败/取消保存安全 rejected；显式重试保留独立尝试。
4. PC 状态可选返回当前任务历史；Office 严格解析并核对文档和任务，重开恢复，时间线折叠详细记录。
5. 验证真实 PC 链路、窗口、损坏、错误字段、异文档与异任务，执行类型、静态、相关全量回归、构建与独立审查。

范围为生产期图片字节解析。ready 不证明版权、来源真实性、品牌合规、编译、视觉 QA 或宿主验收。完整网络获取与全部素材获取记录、最终交付事件仍需继续实现。历史任务选中后不混用最新任务素材历史。
