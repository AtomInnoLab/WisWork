# PPT Agent：页面截图、结构检查与可恢复 QA 记录

基线 a3d0678；继续执行已批准方案 O4。沿用高保障流程和隔离分支。

## 实施范围

对已确认导入的页面，通过真实宿主 slideId 定位，不依赖前20页全局检查。采集原生截图和有界几何结果，按项目/生成请求/业务页/宿主页绑定 QA 记录。结构检查、截图采集、Agent 视觉判断分别记录，来源核验与保存重开验证保持未完成。

- 截图/结构由 PowerPoint API1.10 的同一目标页读取，截图返回给模型并保存会话 PNG 副本。
- metadata 持久化到文档设置，不把大图写入 settings。历史记录可恢复，但始终标记需重新采集以确认当前状态。
- Agent 视觉复核只能针对当前会话已返回的截图；复核落盘前重新采集，截图摘要/结构变化时拒绝旧判断。明确 reviewer=agent，不标成人工验收。
- 只检查导入回执中确认完成的页；未知写入或无映射页不接受检查。

## 契约与边界

QA record version1，绑定 documentId/projectId/requestId 和源 PPTX base64 的 SHA256。最多32页、每记录64KiB；设置最多8条记录、总256KiB。页记录含业务页ID、宿主ID、时间、截图摘要/大小、结构计数与截断标志、visual状态和Agent说明。

结构状态：完整且无告警为 passed；有越界/重叠为 warning；截断为 incomplete。重叠仅是几何线索，不自动判为设计错误。视觉状态默认 needs_review；显式 Agent 判断可记 pass/needs_changes，必须对应当前会话已展示且复采未变化的图。

不引入来源事实验证、真实Office自动验收、模型自动修版、保存重开验证或跨会话截图长期存储。

## 单元

1. 宿主适配器：按slideId精确采集结构与截图、边界和能力检查、mock测试。
2. QA技能：capture/read/review、映射/摘要/生命周期校验、历史与新鲜状态、复核陈旧检测与测试。
3. 设置持久化与运行时/UI：严格记录校验、保存失败回滚、导出QA JSON、只读历史展示、跨层测试。
4. 独立审查；全仓测试、类型检查、lint、两端构建；阶段报告。

## 独立审查后的必要修正

Office transport 原来只发送 tool result 文本，丢弃实际图像。补齐 Anthropic 图片块转换，旧工具轮明确提示图片需重新采集，最新工具轮图片完整传递；总请求按 UTF-8 保持256KiB上限。宿主截图按确定宽度逐级降采样至64KiB预算，仍过大明确失败。增加实际QA capture到transport请求体回归，以及高熵PNG降采样与超限回归。恢复生成物后通知QA/导入状态订阅者刷新。
