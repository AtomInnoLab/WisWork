# 写入回执与中断恢复提示

依据原方案 §7.2/§8.10，默认恢复提示应说明影响范围、已完成工作、自动动作和用户下一步。

1. 提供纯展示投影：阶段使用既有语义映射，导入/修改回执使用有界计数，避免工具名、内部阶段和参数直接进入默认文案。
2. 重开提示和当前传输失败提示复用投影；当前错误从最新检查点读取回执，不使用启动时旧快照。
3. 导入完成仅代表导入记录，修改结算包括撤销/丢弃，不能推断写入或视觉验收全部通过。前台中断不推断后台终止；未知/损坏回执不显示虚假成果。
4. 通过投影、会话错误路径和实际持久检查点验证回执变化、不重放写入、计数边界和无内部细节；完成类型检查、相关完整测试和构建。

不增加自动写入恢复。已有持久工作台和确认式核查/续写/撤销入口仍负责具体宿主动作。
