# 完整计划版本恢复

原方案要求项目持久恢复、逐步修改保留研究/资产/成果，完整版本应可追溯。

1. 保存计划时先原子归档上一完整版本，再提交当前计划；最近 32 个修订窗口有界保留。读取旧版本核对文档、项目、修订和当前历史中的内容摘要。仅在归档缺失时可使用摘要一致的冻结编译任务计划；不存在时明确不可恢复。
2. 既有 get_plan/read_presentation_plan 增加可选 revision，默认仍读当前。请求历史版本不得静默回退到最新。
3. 工作台选择旧计划恢复为新修订：读取并比对历史摘要，继续当前 CAS 保存，刷新验证状态；相同内容不产生伪修订。已有宿主页、后台快照和验收记录不自动迁移。
4. 先跑失败用例，再验证归档损坏/符号链接、保存中断、窗口清理、旧冻结计划、并发/取消、真实 PC 重开与生产复用；完成类型/静态检查和构建，保留独立复审与实机门禁。

边界：历史可用性受保留窗口及旧版材料限制，品牌约束仍由既有规则执行，不伪造品牌认可或放宽约束。锁页与宿主成果关联继续后续实现。
