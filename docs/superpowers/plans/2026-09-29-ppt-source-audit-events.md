# 真实资料核对的持久研究记录与恢复

按原方案 §7.1、§7.2 和 O1 接通真实资料核对过程；事件范围明确为 source_excerpt_audit，不推断整个研究或来源真实性完成。

1. Project Store 原子保存有界核对台账，冻结计划修订/摘要和资料身份，记录开始、结果或失败。保留未决记录，拒绝不匹配的完成范围和损坏；相同明确 ID 幂等返回。
2. PC 既有 audit_sources 路径执行前保存开始，保存结果后返回；失败记录安全错误代码。旧调用不新增必需字段，明确核对 ID 可重放原记录。状态只返回有界历史摘要，单次结果单独读取。
3. Office 严格解析、重开读取与当前计划匹配的历史结果；资料/计划变化不沿用旧记录。取消、文档切换、迟到和读取失败不污染当前状态。
4. 工作台将同一计划版本的核对合并为一个阶段记录，保留次数和时间；旧修订与未决核对明确区分，未决不虚构仍在后台执行。已有当前资料状态独立重读。
5. 验证真实附件、PC 服务重开、错误和未决恢复、Office 组件/控制器；运行持久项目、规划、修改、锁页和时间线相关回归、类型、静态检查及构建。原方案完整研究、批准及交付事件仍继续推进。
