# 计划修订后的受影响页面重算

原方案 Stage C/D：修改计划保留研究和资产，仅重算受影响页面。

1. 为真实页生产输入生成可比较的页面作用域：共享计划/样式、实际页内容、页主张和来源、使用的素材，以及显式依赖的递归输入。缺失/非法结构拒绝复用。
2. 创建生产请求时复用最近同项目/文档任务中的已编译且输入相同页面。保持原任务不可变，持久记录逐页来源，重开时校验来源输入与结果一致。新请求仍绑定当前计划修订。
3. 将复用来源投影到插件页状态；默认制作和后台任务跳过已编译页面，不迁移来源/视觉验收或宿主导入回执。
4. 验证局部内容/依据/素材/共享样式/依赖变化、删除与顺序变化、部分完成、幂等和磁盘篡改；运行项目存储、Shell 与 Office 回归、类型/静态检查及构建。

保留未完成项：页面锁定与交互编辑、独立复审、真实宿主验收。不得把编译结果复用视为验收完成。
