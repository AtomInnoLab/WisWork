# 原方案阶段6：原生图表品牌样式生产与回读

基线：c2020e8f。沿用 v1.3 的 StyleSpec、品牌检查稳定通过和原生可编辑图表目标，不新增品牌 schema，不将包结构测试当作视觉或实机验收。

## 发现与设计

现编译图表只明确指定数据 accentColor、坐标轴字体及图例字体。数据标签、文字颜色、背景、轴线与网格线仍可能依赖生成器默认值；编译后验证偏重数据及选项，Office 比较只识别方向/分组/图例/数值标签选项。采用既有 StyleSpec 控制这些实际可见样式，验证实际生成的 OOXML，并在已有 Office 包回读中识别已知显式样式差异。

未知主题、继承或复杂效果维持 unchecked；保留原有图表缓存、工作簿公式及数据校验。包颜色/字体一致不证明实际视觉可读性、品牌真实性或专业任务通过。

## 实施单元

1. PPTX compiler 明确 bar/line/pie 的文字、图例、轴、线、背景及数据样式，并扩展编译后真实包验证；先复现默认漂移及样式篡改。
2. Office chart 包观察器对受支持显式样式归一化比较，保持原 chartStyleChanged/unchecked 合同；真实 XML 篡改保留数据和几何也应识别。
3. 实际 PC 保存计划/编译/生产链验证品牌 StyleSpec 进入实际 PPTX；根实际 QA 工具与回读验证问题暴露。
4. 不同实现者交叉审查、最终相关工作区完整回归、类型、格式和构建，记录进度及未完成专业/宿主退出门槛。

回退：代码回退本批提交；不迁移持久数据。外部身份注册、部署及实机验收不在本批自动执行。
