# 现稿图表数值持久重新应用

目标：按产品方案阶段 5 的撤销与重新应用，支持受限原生图表数值修改重开后重做。基线 a26a83a8，沿用隔离实现分支。整页重做仍独立待办。

架构：图表记录新增可选有界 values 数值矩阵与 reapplies 原 change ID，保留旧记录可读。重新应用只接受 undone 且保留备份和数值的记录，读取原备份、核对恢复页 ID/页序/完整包摘要，再沿原 proposeChartValues 生成独立新变更并关联旧历史；旧记录不变。

约束：values 与 provenance 属于不可变身份。合法矩阵限制与首次工具一致，不能无限增长或突破记录容量。重做前和确认执行时原记录、宿主页包与原备份均需核对，缺失/释放备份拒绝且不自动重建。重新计算后包必须与旧 afterPackageDigest 一致。新记录可独立恢复及撤销；不重放结果未知的写入。高风险包替换继续保持明确提案。默认 QA 失效策略不可缩小到未经证明的范围。

1. 核心单元：presentation-existing-chart.ts、powerpoint-skill.ts 及相关测试。持久数值与不可变关联，reapply_slide_chart_values_change(change_id) 工具，复用初次数值修改/备份/回读。失败先行测试覆盖重开成功循环、旧记录缺数值、释放/缺失/篡改备份、当前页人工修改或身份变化、确认后旧记录变化、丢回执以及再次撤销。代码与测试 scoped commit。
2. 工作台单元：presentation-changes.ts 与控制器/卡片测试。undone 且 values/备份未释放显示重新应用，精确 change ID 路由；显示关联来源，已撤销页定位使用 restoredSlideId。工具返回新旧变更关联，刷新历史后新记录单独可操作。
3. 独立整体审查，Office 全套测试、类型、lint、格式与差异检查。更新进度且保留真实 PowerPoint 未验收状态。

兼容：可选字段不改既有记录，旧记录不能重做；无新依赖或新数据目的地。回滚前必须保留可读取新增记录的恢复通道，代码完成不代表上线或真实宿主完成。
