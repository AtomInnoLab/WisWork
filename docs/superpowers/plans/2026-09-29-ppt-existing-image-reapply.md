# 现稿图片持久重新应用

目标：原方案阶段 5 的撤销与重新应用覆盖普通原生图片，重开后不依赖临时 VFS。基线 1b46ad16，隔离实现分支。整页和图表的独立重做继续保留为后续任务。

架构：首次图片替换在本机 PC 备份原图与已验证的替换素材；记录可选替换素材备份元数据。撤销后图片具有新形状 ID，因此重做经确认创建新的图片 ChangeSet，并关联原 change ID，原记录保持 undone；复用现有替换、回读、恢复、撤销循环。

约束：旧记录兼容但没有持久素材时不能声称可重做。写前核对恢复图片的媒体、几何、旋转、名称、辅助文字、层级及周围形状，验证原图与替换素材备份字节；不自动补建丢失备份。重做清除历史视觉审阅。每个新记录仍可独立恢复和撤销，未知插入结果不能自动重放。记录新增字段受严格 schema 和身份转换限制。全部数据经已有获授权的本机 PC 备份路径。

1. 单个完整实施单元：修改 presentation-existing-image.ts、presentation-existing-image-editing.ts，以及 presentation-document.ts/历史消费者（如必要）；加入 sourceBackup 与 reapplies 等有界可选字段，新增 reapply_existing_presentation_image_change。工作台只给具备持久素材的 undone 图片记录重做入口，宿主 QA 仅受影响页失效。具体 schema 应复用既有备份元数据验证。工具结果返回新旧 change ID；原记录不得被更改或复用旧形状 ID。失败先行回归涵盖替换→撤销→重开→重做→撤销、旧记录不展示、素材或原图缺失/篡改、人工修改、插入回执丢失，以及新历史路由与 QA 范围。实现与测试一并提交。
2. 独立审查完整差异，运行 Office 全套测试、类型检查、定向 lint/格式及差异检查；修复重要问题。记录真实 PowerPoint 尚未执行以及方案进度。

兼容与回滚：可选字段保持旧记录可读，旧版不理解新字段时保守拒绝，现有构建版本门禁保持有效。无新依赖或外发目的地，未上线发布。回滚代码不能丢弃已写入的新记录，须保留当前构建恢复通道。
