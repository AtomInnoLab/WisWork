# 宿主锁页覆盖确认与提交前复核

依据原方案 §4.4、阶段 E 与设计门禁要求，延续计划锁定和精确源产物核对。

1. 复用原生 QA 的可信范围判断；稳定 Slide ID 操作只覆盖对应副本，未知脚本/包范围按可能影响的全部锁页展示。新增页、本地记录与候选页准备不视作覆盖原页。
2. 提案控制器异步读取锁页证据，审核期间不能确认；失败保持可拒绝。结果只更新同一提案事件，取消或迟到响应不恢复旧提案。
3. 按文档有效回执和当前项目读取所有相关 PC 当前计划，精确核对冻结源与旧整稿页身份，读取实际宿主页面。不使用工作台缓存。回执冲突、未决导入及不可证明身份拒绝。
4. 展示锁页标题和副本数量，确认本次覆盖不解除计划锁。提交在异步 QA 保存后再次读取计划、源、回执与宿主页身份，审批证据变化即拒绝；随后沿用原工具的保存点、宿主回读与撤销机制。
5. 验证实际 HostRuntime、真实 PC 服务重开及显式解锁、会话事件更新、迟到/取消和 UI 禁用，再运行审批/原生修改相关回归、类型、静态检查及生产构建。真实 PowerPoint 与独立复审仍是单独门禁。
