# 持久计划页锁定与执行保护

原方案 Stage C 提供锁页，Stage E 对覆盖锁定页确认，§8.10 不阻断读取与诊断。

1. 页任务支持可选 locked；锁定状态随完整计划、修订和冻结任务保存。普通计划保存不得删除、移动、解除锁定或间接改变锁定页的样式、引用与依赖。
2. 工作台明确的锁定/解除操作通过专用 PC 操作携带当前修订；Agent 普通保存不能借删除字段解除锁。使用既有摘要、CAS、文档与取消保护。
3. 生产输入核对当前锁定页；页重建同时保护直接目标和因依赖而受影响的锁定页。锁定状态本身不改变编译内容，不使既有成果失效。
4. 验证存储重开、实际 PC 路由、工作台操作、错误传播和跨层回归；宿主覆盖保护需要成果映射，后续接通后才可宣称完整锁页能力。

锁定不代表批准、事实核验或 QA。旧后台冻结任务与已导入宿主页的保护范围须分别验证。
