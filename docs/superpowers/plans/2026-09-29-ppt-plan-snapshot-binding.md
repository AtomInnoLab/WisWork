# 规划修订快照与当前内容绑定

依据原方案第 7 节，规划、研究和样式的展示必须能够追溯到当前持久项目内容。

现状：PC 存储已核对最新修订快照的组件摘要，插件接收状态时只核对数量。同样数量的内容变化仍可能与旧摘要混用，影响修订展示。

实施：

1. 复用存储现有确定性序列化，提供不含 Node 依赖的共享入口。
2. 插件异步核对最新快照的资料、主张、页面和样式摘要，保留无快照旧记录兼容。
3. 核对后继续验证取消和文档绑定，拒绝过期结果。
4. 用真实摘要验证成功路径、同数量内容变化、取消与摘要失败；独立审查后执行相关完整测试、类型检查和插件构建。

范围：提升现有持久记录的证据一致性，不把工具操作或快照登记解释为研究/样式审批完成。
