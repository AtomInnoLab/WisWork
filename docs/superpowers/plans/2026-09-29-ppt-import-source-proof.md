# 精确导入源产物核对与旧整稿页级关联

按原方案稳定页身份、BuildReceipt 与恢复要求，补齐持久导入记录的源产物证据。

1. PC 只读 read_import_source 按编译/生产命名空间、项目、文档、请求读取不可变任务，返回冻结页身份、计划修订及与旧回执一致的内容摘要，不返回 PPTX 正文；未完成、错误身份、损坏拒绝。
2. 抽出浏览器可用的原始序列化，保留旧完整文件/生产包摘要契约；用独立固定输入验证兼容，真实 PC 与浏览器比较验证。
3. 工作台每批最多四个独立只读请求，核对准确响应身份、64 KiB 限额、取消、文档切换及回执变化。摘要或源页映射不一致不发布关联；不可用明确为尚未核对。
4. v2 和 v1 checkpoint 逐项验证摘要与源页顺序，旧完整整批回执通过原始任务页序与保存的 Slide ID 顺序恢复来源身份；没有回执摘要则明确身份关联，不能冒充文件摘要验证。
5. 执行源产物、持久恢复与工作台回归、类型和静态检查及构建。下一步宿主覆盖确认须使用提交前新读取的锁定状态与有效映射，不能使用只读 UI 状态代替执行保护。
