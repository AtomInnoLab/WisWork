# 现稿单对象重新应用

依据原方案阶段 5 的撤销与重新应用，扩展单对象文字、等长文字范围、几何及表格单元格 ChangeSet。基线 e17dabae，沿用隔离实现分支。

设计：仅已撤销且原页备份保留的记录可重做；读取并验证 PC 原备份后才持久转入 pending，清除历史审阅，复用原有写入、回读及恢复流程。目标当前值与保留字段必须匹配撤销后的原值；不重新生成缺失备份。每次重新应用经提案确认，支持重开恢复和再次撤销。备份释放后的历史记录拒绝重做。原记录的目标、修改内容及备份身份保持不变。

1. 核心工具：新增 reapply_existing_presentation_change，覆盖成功循环、备份异常、人工冲突、失去回执；先观察新增测试失败，再实现。核对持久状态转换消费者。
2. 工作台及 QA：已撤销且未释放备份显示重新应用，按精确 change_id 路由；仅受影响页 QA 失效。失败先行回归。
3. 独立审查完整差异，Office 全套测试、类型、lint、格式与差异检查，记录进度。真实 PowerPoint 验收仍单独计数。

实现边界补充：现有 pending 状态不记录是否来自重做。为使重开恢复遵循相同原保存点约束，所有已有单对象记录的 resume 均要求原备份可读；仅首次 edit 可创建备份。备份缺失时拒绝自动补建，保持现稿不写入。
