# PPT-P0-09 候选材料包：历史披露与情景假设

状态：**官方历史披露、自制假设与独立复算已冻结；财务审阅和真实 PowerPoint 验收未完成**。本包只计候选材料，不计专业任务通过。

## 三份输入与权利边界

1. `apple-fy2024-q4-financial-statements.pdf`：Apple 2024-10-31 [官方披露](https://www.apple.com/newsroom/pdfs/fy2024-q4/FY24_Q4_Consolidated_Financial_Statements.pdf)，四页。第 1 页为**未经审计**的合并经营表，取“截至 2024-09-28 的十二个月”列。历史净销售额 391,035、营业利润 123,216，单位均为**百万美元**。公开披露仅用于本基准的来源核对；不声称 Apple 授权、认可或发布本包的情景分析。
2. `model-inputs.json`：WisWork 为测试自制的模型说明，固定截至日期、历史输入、三组增长率/营业利润率、逐步四舍五入公式、八页要求和禁止主张。它不是 Apple 指引或预测。
3. `scenario-results.csv`：按模型独立复算的三组结果；`evidence_type=calculated_hypothesis`，图表和叙述均须保留此身份。增长率和利润率使用基点；每一步按百万美元四舍五入。该表不是历史披露。

`p0-09-reference.pptx` 是用同一模型编译的八页**参考产物**，含两张原生情景图表；不是 Agent 执行结果。运行 `node -r tsx/cjs generate-reference.cjs` 可重建。`SHA256SUMS` 冻结三份输入和参考产物；运行 `node verify-materials.mjs` 同时核对 PDF 页数、历史表格列、模型公式、三情景 CSV 及图表底层数值。官方 [发布页](https://www.apple.com/newsroom/2024/10/apple-reports-fourth-quarter-results/)可核对发布日期。来源 PDF 的权利归原权利人，勿将其当作开放许可图片资产。

## 固定任务提示

> 以本包 2024 财年官方披露为**历史事实**，以自制模型说明为**假设**，制作八页中文 16:9、原生可编辑的情景分析汇报。第 3 页必须保留 2024 财年期间、单位和未经审计状态；第 4 页列明增长率、营业利润率及公式；第 5、6 页分别用原生图表展示三情景的净销售额和营业利润，并核对底层数值与 `scenario-results.csv`。所有情景页显著写明“假设性演示，非 Apple 指引或预测”；不能把情景值说成已发生事实，不能推算模型未覆盖的净利润、现金流或股价。第 7 页解释对增长率和利润率的敏感性及模型遗漏，第 8 页列出来源与待财务审阅事项。保存页级计划、来源/主张台账、独立复算表、图表数据回读、截图、交付 PPTX 和关闭重开后的编辑证据。

## 执行门槛

- 财务审阅人先核对历史披露的期间、单位、审计状态和三组假设是否适合作为测试输入；若改数值，提升版本并重算摘要。
- 真实 PowerPoint 中核对图表原生可编辑、底层数值与 CSV 相同，保存关闭重开后再查；素材包没有预填通过结果。
- 本案例固定 `asOf=2024-10-31`，禁止把后来年份的披露混入本次历史基线；若改时点需新建版本。
