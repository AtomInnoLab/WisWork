# PPT Agent：研究中断记录的显式结束与恢复

日期：2026-09-29。基线 `bc25b166`，依据原方案研究流程、持久项目与失败恢复。本批打通 Store、PC 服务、Office 工作台和真实 Runtime 跨层链路。

## 完成内容

- 对精确身份的未完成研究提供二次确认结束，保存为 failed/aborted，保留草稿、序号、摘要和附件；不重跑原研究。正常执行中的研究与结束操作共用项目锁，正常结果不会被覆盖。
- 恢复身份先持久保存，取消等待、丢失回执和重开后只读核对原记录；显式重试保持原 CAS 和身份。记录终态不等于证明是哪次请求结束了它。
- 确认终态后读取真实研究列表获得新版本，能够继续清理和新建研究；刷新失败清空旧版本，防止用过期 CAS 继续操作。另提供二次确认仅清除本机恢复身份，不修改 PC 记录。
- 新旧 PC 能力三段兼容，旧客户端请求与响应形状保留；Agent 不新增结束工具。
- 修复失败记录本身的 error 字段被误认作接口错误，实际失败研究仍可通过严格结构、草稿 SHA 和完整身份验证后读取、导出。
