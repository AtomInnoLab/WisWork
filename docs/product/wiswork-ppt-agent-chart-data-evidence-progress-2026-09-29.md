# PPT Agent：图表逐点数据依据与冻结复核

日期：2026-09-29。依据原方案 §4.3.1 科研图表忠于原始数据、金融单位币种及证据先于表达要求。

## 完成内容

- 冻结计划可声明每个图表的对象 ID、类别、系列、逐点值与主张。每一点选择计划来源摘录的原样 UTF-16 数值依据，或现有计算主张的受限算术结果；主张必须属于本页，来源必须属于该主张。旧计划与 SlideIR 继续兼容。
- 预检逐个比较声明与实际图表，记录八类缺口：未关联、图表缺失、标签/维度不同、数值不同、原文数值依据不符、计算未复现、单位缺失或不同、币种缺失或不同。未关联图表没有主张时保留图表缺口，不编造主张 ID。
- 数值依据按原字符比较，不推断千分位、百分比、中文数字、单位转换；拒绝从更大的数值、符号、小数或指数表达中截取数字。英文逗号紧邻数位时也保守拒绝片段，CSV/分组数字需明确可核验的原数值摘录。已知单位或币种被省略仍显示缺口。
- 页面预检和交付报告保留完整实际图表数据及逐点声明。报告解析按冻结计划和实际快照重建检查，删除必需检查或隐藏差异会拒绝；受影响主张进入无法核验问题链，相关摘要包含完整图表检查和本页绑定。supported 或 explained 不能消除差异。
- 报告页仅有图表检查时增加最多 256 条问题容量，保持旧非图表页上限和旧问题摘要；整报告 8 MiB 上限不变。JSON/Markdown 和本机交付 ZIP 保留原研究、声明、实际值与缺口。
- Taskpane 默认折叠图表明细，展示中文原因、实际数值表、逐点主张、原来源位置或计算公式，以及声明单位/币种。切换任务不展示旧数据。Agent 规划指引使用现有原文读取、页面检查与报告工具，没有新增未经支持的工具。
