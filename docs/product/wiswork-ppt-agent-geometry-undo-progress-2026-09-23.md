# PPT Agent：几何修改保存点与撤销

日期：2026-09-23。基线`e81ab5be`，分支`codex/ppt-agent-implementation`。

## 1. 目标与状态

依据原方案§6.4、§8.7、§11.8、§14、§20/21，补首批撤销能力的可验证基础：稳定业务页原生对象位置与尺寸修改的持久化保存点。首批撤销、单页重做、O3/O4及P0继续为**进行中**，不将局部能力表述为完整ChangeSet。

## 2. 完成项

- 在Office文档设置保存最近一次几何修改的前后值、文档/任务/来源/业务页/宿主页/对象身份和产物摘要。
- 修改前保存pending，宿主回读后标记applied；撤销前保存undo_pending，回读确认恢复后标记undone。完整记录CAS和不可变身份防止并发覆盖。
- 提供读取保存点与撤销工具，重新打开插件并恢复相同任务后可以读取记录。撤销要求目标对象当前几何与记录相符，手动调整后拒绝覆盖。
- 文档内仅保留一个几何保存点，未完成或不确定记录不能被其他任务覆盖；重复撤销不重复写入。
- 撤销沿用现有提案确认和QA写入互斥，仅使对应宿主页的QA失效。

## 4. 未完成与偏差

- 本批仅位置与尺寸；没有恢复富文本格式、图片对象、动画、整页或通用脚本。文字适配器目前未保留完整富文本，不能以恢复字符串冒称完整文本撤销。
- 只支持最近一次已记录几何修改，无多步历史栈或跨对象变更集。文字/图片修改不被该保存点覆盖；工具名称明确限定几何。
- pending/undo_pending结果不确定时只报告并停止，没有自动重放、推断完成或用户侧解除入口，需进一步人工核对和后续恢复能力。
- 单页重做、完整撤销、内容证据QA、真实RoundTrip、20项专业材料/实机验收仍未完成。测试数不代表P0通过率。

## 5. 风险变化

新增宿主写入前的可持久化几何前值与撤销保护。保存失败时停止，回读完成后的记录保存失败仍保留pending而不宣称完成。撤销允许0.01pt几何回读容差，传给宿主比较的预期值使用刚读到的实际值，避免量化误差与手动变化混淆。

保存点最多16KiB，采用独立设置项。旧客户端可能继续修改对象导致保存点过期，升级后撤销仍需新鲜度检查；同值人工改动无法由数值比较辨识。
