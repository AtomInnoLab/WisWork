## 2. 完成内容

- `save_presentation_page_backup`：由明确的已编译单页修订定位父任务；要求当前准备的父生产任务具有完整导入回执，并核对文档、产物摘要和业务页映射，按稳定宿主页ID读取。
- Browser adapter通过Office.js单页导出，保存有序宿主页ID列表；读取期间目标消失、身份不符、页序变化或超过512页会拒绝，不按旧索引猜测目标。
- PC新建独立备份目录，保存原始字节、SHA-256、目标宿主页、页序、父子请求及输入摘要。元数据与备份ID绑定不可变；校验同一项目和文档，禁止用新内容覆盖旧备份。
- 128KiB分块上传，重复块核对已有前缀后继续；完成前校验大小、摘要、受限ZIP与单页PPTX结构。备份不通过重新生成或重写包得到。
- `read_presentation_page_backup`：插件或PC重启后，可凭项目和备份ID读取历史文件；再次核对下载字节SHA-256后写入会话文件，拒绝覆盖已有文件，不向模型返回base64。
- 清会话、取消、切文档、活动父成果或导入回执变化会阻断后续步骤；不自动执行宿主替换、删除、恢复或QA通过。

## 4. 限额与失败语义

- 每份备份最多8MiB，每项目最多8份（含未完成），单次分块128KiB；ZIP最多2048项、单项解压10MiB、总解压32MiB，拒绝ZIP64、多磁盘及不支持的包。沿用256KiB请求限额，不自动删除旧备份释放容量。
- 续传要求重新导出的**字节与已登记摘要相同**。若用户修改页面或Office重新导出改变包内元数据，同一backupId会安全冲突；不能据此宣称实机任意中断均可续传。历史已就绪备份不受影响，新快照需新ID。
- 备份是历史保存点。它不证明当前页面仍等于备份、不证明当前页已通过QA，也不是已经完成的撤销记录。后续替换仍需新鲜内容/位置核对、写前事务记录和写后回读。
- 备份保存于配对PC的本地用户数据，不保证PC磁盘丢失后的恢复。文件与目录持久化沿用平台能力，Windows无目录fsync时仍完成文件fsync。
- 新工具当前只接已完整导入的父生产任务，不扩展到任意手工现稿或尚未导入的编译结果。
