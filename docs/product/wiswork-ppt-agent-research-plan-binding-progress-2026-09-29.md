## 完成内容

1. 制作计划增加可选研究绑定：指定 ledgerId、sequence、draftDigest，以及计划来源/主张到原研究 ID 的显式映射。研究 ID 保留原长度范围，不截断；计划 ID 可使用别名。严格检查未知字段、重复映射、目标存在性和引用。
2. 引擎核对 completed 归档身份与原文 URI、快照、摘录、位置、时点，以及结论类型、陈述、适用范围和计算原始字段。计划可选部分引用并补算术复算说明，但不能改写原研究限定。声明可信度不构成来源认证，所有主张继续需要复核。
3. 输出未映射主张、遗漏冲突方、未选来源引用及来源不可用四类缺口；保留完整研究记录，包含未被计划选择的来源、相反结论和原始建议页面。双向或单向声明的冲突均可发现；不把有缺口的研究自动标为通过。
4. 真实 PC 保存计划、历史计划恢复保存、编译/生产冻结、派生页及后台任务启动/恢复读取指定原归档。检查在新计划、任务或 job 启动回执持久化前完成；损坏/缺失及身份不符返回安全错误。稳定版本 CAS/丢响应重试保持原幂等行为，取消/暂停仍可操作。
5. 交付报告根据冻结生产计划读取指定归档，不读取项目最新研究。报告构建重算草稿 SHA；同步解析校验完整形状、身份映射和重新计算的缺口，不声称认证原始来源。PC 原研究 Store 的读路径同时核对持久状态校验和及真实草稿摘要。
6. Office 规划工具说明如何先读取真实研究再显式映射，不猜 ID/摘要。项目卡展示版本/映射范围并打开指定研究；真实 Runtime 读取明确 ID 并核对文档、项目、状态、序号及摘要，取消/文档切换/迟到结果有保护。报告卡展示完整冲突双方和中文缺口；旧无绑定计划、报告维持兼容。
7. 当前宿主完整 ZIP 优先附冻结报告的研究版本；仅无绑定计划可附读取时项目历史研究，并明确范围。PC 完成包时要求绑定研究文件存在、与报告记录完全相同且与实际原归档相同；重新计算全部文件/ZIP 摘要也不能绕过该约束。导出成功仍不产生项目完成或当前宿主内容核验。
