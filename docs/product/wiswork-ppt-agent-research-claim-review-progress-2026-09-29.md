4. 真实 PC 主张证据接口从冻结计划指定归档读取完整原 Plan claim、文档身份、来源 as-of、原研究绑定、完整 Record 及本主张引用缺口。保留类型、时点、适用范围、计算基础、所有冲突/未选来源、原检索时间、声明等级及可信度，不读取 latest 代替原 A。

6. 有绑定的证据总量限 512KiB，适应完整原研究；无研究保持 256KiB。原文窗口仍最多 8000 UTF-16 单元，附件/ZIP/报告上限不扩大。插件在 JSON 前后应用相应容量，核对当前文档并重算研究草稿 SHA，再计算全证据摘要及发布有限会话缓存；取消、换文档和迟到结果守卫保留。响应摘要改动但仍携带旧 SHA 会拒绝，不开放后续写判断。
