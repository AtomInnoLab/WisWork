# PPT Agent：单页派生重编译

日期：2026-09-23。基线`de9674c7`，分支`codex/ppt-agent-implementation`。

## 1. 目标与状态

依据原方案§5阶段D/E、§6.3、§11.3/11.6、O3、§20/21，补单页重做的编译基础：只重编目标页，保留原任务和其余成功页。宿主单页重做、完整撤销及P0仍为**进行中**。

## 2. 完成项

- 新增从明确父任务派生单页修订的操作。父任务必须全部编译成功；PC从父冻结输入构造修订，调用方仅提交目标页内容，不能修改其他页、全局样式、资产或主张。
- 保持业务页ID、标题和引用映射符合父计划；目标页可调整内容、布局和备注，引用父任务已有资产。计划需变更时应重新规划，不通过本操作绕过。
- 原子保存完整子任务：其余页记录和产物原样复制，仅目标页pending。随后沿用逐页执行工具，只编译目标页；失败重试不重复制作其他页面。
- 修订记录保存父任务、父输入摘要和目标页，重复同请求幂等，其他父任务/输入冒用请求ID拒绝。原任务不改写。
- 插件新增单页重编译工具与修订来源提示，目标页产物仍可下载。修订任务禁止走整批导入准备，避免错误追加整套页面。

## 4. 未完成与边界

- 本批是PC单页重编译，不会替换当前PowerPoint页面，也没有整页撤销。宿主替换需要原页持久备份、新旧宿主页ID映射和可恢复事务，下一批接入。
- 原计划的资产、主张、样式、页身份固定，不能借此更换全局主题或新增来源/图片。父任务必须全部成功，不处理部分完成父任务的派生。
- 复用产物仍各自计入子任务容量，未引入共享文件引用或跨任务垃圾回收。
- 真实RoundTrip、内容证据QA、完整ChangeSet、20项专业材料和实机验收仍未完成；本批没有测量P0交付率。

## 5. 风险变化

降低单页重做触发整稿重复编译的成本，并保存父版本作为后续替换的可核对基础。原子发布避免中断后其他页被误视为未编译；严格父身份与输入限制防止复用错误成果。

继续沿用每项目32个任务、每任务总产物10MiB和17MiB记录等限额；复用副本不绕过限额。旧PC可能拒绝包含修订记录的项目，需配套发布，不删除历史成果来降级。
