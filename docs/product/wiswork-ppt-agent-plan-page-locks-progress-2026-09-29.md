# 持久计划页锁定与生产保护（2026-09-29）

## 原方案对应

Stage C 提供锁页；Stage E 对覆盖锁定页要求确认，并保留读取、诊断和资产准备。本轮实现计划与本机生产层的持久锁定，宿主覆盖保护仍需通过成果映射接通，不能宣称完整锁页验收完成。

## 已完成

- 页任务支持可选 locked，旧计划缺省未锁定。锁定/解除通过工作台明确操作及专用 PC 请求，携带当前修订号；解除权限不暴露给普通 Agent 计划保存。操作产生可恢复的新修订，不改变已有 PowerPoint 页面。
- 普通保存不能删除、移动、解除锁定，或改变锁定页的任务、共享样式、Brief、品牌、所引用主张/来源及递归依赖。其它页的无关内容修改仍可保存；历史恢复也遵守现有锁定。
- 已有本机生产输入的锁定页保存固定输入摘要，优先选最近匹配计划的页生产记录、其次旧整稿记录；尚无匹配输入时在首次接受生产输入时固定。锚点及摘要随当前计划原子保存，重开保持；缺失、损坏及页身份不一致拒绝读取，不重新挑选保护依据。
- 统一保护新页生产、整稿编译及单页重建入口。新请求不能更改已固定的锁定页输入；不能通过不绑定计划的编译绕过锁定。重建锁定页及会影响锁定依赖页的重建拒绝，须先由用户明确解除计划锁定。
- 锁定标记不参与编译内容比较，添加锁定仍可复用未改变的既有编译成果。已接受的后台请求继续按原冻结输入执行；本轮不撤回旧请求，也不改变宿主导入和验收身份。
- 工作台显示锁定状态及显式解除按钮，锁定页移动/删除禁用，前台忙碌时禁用操作。复用文档身份、取消/迟到响应、精确计划回执及刷新验证，Agent 工具保留具体锁页错误与用户提示。
- 通用存储原有不透明 JSON 读取保持兼容；PC 服务仍要求结构化计划通过 schema 校验。
