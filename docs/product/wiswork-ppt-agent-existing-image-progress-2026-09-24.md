## 本阶段完成

1. 对现有演示文稿的普通原生图片，基于新鲜页面/对象基线、准确的宿主 ID 和已校验的 VFS PNG/JPEG 发起确认提案。确认后先读取并持久备份原始图片，再保存未决记录，最后调用 Office 原生图片替换适配器；写后核验图片内容、位置、尺寸、旋转、层级、名称和替代文字。
2. 新增独立于生成项目的现稿图片变更记录，包含原图备份、替换图摘要、原生对象 ID、作用域及恢复状态。Office 设置存储和统一历史列表采用比较并保存、空间预留与回滚；重开后仍可读取。
3. 对中断的替换，仅在已记录的新图片候选和宿主现场一致时继续删除旧图或补齐完成回执，不自动重复插入。撤销从持久备份恢复原始图片，同样保留中断恢复所需对象 ID 和保存点。工作台可查看前后图片摘要与恢复/撤销入口；修改使目标页 QA 失效。
