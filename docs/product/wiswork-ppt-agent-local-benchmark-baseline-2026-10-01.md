依据[完整方案](./wiswork-ppt-agent-solution-and-implementation-plan-2026-09-22.md)阶段 0 和 §17，记录固定任务在本机构建版 Taskpane、Electron PC、Rust Relay 上的可复跑工程耗时。环境为 Linux x86_64、16 个逻辑 CPU、Node.js v25.8.2；本次没有运行跨平台 CI。

## 测量口径

命令为 `node tools/ppt-agent-electron-real-relay-smoke.mjs --benchmark=<case> --built-taskpane`。脚本输出 `ppt_benchmark_timing` JSON 行，仅在对应固定任务的来源上传、PC 配对、八页生产和 PPTX/PDF 回读全部核对后输出。P0-17:all 同时执行科研、法律、金融三个独立八页任务，记录三者共同完成的墙钟时间。P0-20 的第 5 页进程崩溃恢复在该任务段计时之后继续验证。

另用 GNU `/usr/bin/time` 记录整条冒烟墙钟时间；它包含预备合成任务、浏览器启动、并发文档、固定任务和后续恢复，不能当作单个用户任务耗时。下表每个场景各运行 **1 次**，所有命令最终退出码均为 0。
