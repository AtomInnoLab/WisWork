## 完成内容

- 提取现有 OAuth 状态机为共享核心，桌面接口和网关兑换/刷新协议保持兼容。新增浏览器入口、WebCrypto 状态随机数和仅内存会话存储；浏览器客户端必须显式提供 HTTPS 回调与 clientId，不能隐式使用桌面注册。状态、发行方、重放、过期、账号切换及迟到刷新继续校验。
- 接入真实 Office Dialog API 适配器。同源启动页明确跳转到既有身份服务；同源回调先清除 URL 查询与片段，再通过指定来源消息发送授权回调。父窗口严格校验实际来源、回调地址、状态和消息字段。取消、关闭、超时和迟到 SDK 回调都关闭相应窗口；不通过窗口消息传令牌。
- 新增独立团队连接，仅协商 `presentation-team.v1`，复用既有 Relay 校验。访问凭证不进入账号快照或浏览器持久存储，账号信息不冒充已验证团队身份。退出、账号失效、能力不符或连接失效立即停止团队操作，清除内容及本控制器持有的未确认提案。
- PowerPoint 工作台增加配置可用的登录、配对验证码、重新连接和退出入口；连接后可明确刷新身份及权限。团队操作使用独立连接，保留原全局确认卡与实际 PC 账本；团队账号按钮不退出私人工作台。
- 构建输出同源启动与回调页面，配置启用时任务窗格 CSP 仅增加既有网关来源。未配置时登录入口禁用，不默认使用 `wiswork://oauth/callback`。更新 Office README 和本地工作区依赖锁文件，无新增第三方库。
