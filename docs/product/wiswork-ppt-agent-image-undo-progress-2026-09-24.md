# PPT Agent：原图持久备份与图片撤销

日期2026-09-24；基线57fd24ca；分支codex/ppt-agent-implementation。按原方案O5继续补齐每次修改可撤销的工程链路，原方案不变。实机验收继续暂缓。

## 本批完成

- **原始图片备份**：从已核验普通原生图片的单页导出中读取原始PNG/JPEG，写入已有PC附件存储，上传完成后重新读回并核对摘要，再允许替换宿主图片。标准化PNG缓存与原图分离，原始JPEG不会被转换后文件替代。
- **持久撤销记录**：Office设置保存原图附件摘要/类型/大小、替换前后对象快照、撤销方向和恢复对象ID；图片字节留在PC，不写入Office设置或Agent文本。延续队列保存、文档身份/Save As保护、不可变记录和容量预留。
- **确认式图片撤销**：核验当前图片与替换后快照完全一致，确认后先插回原图并核验、保存恢复对象ID，再删除替换图。原图恢复后得到新对象ID。
- **中断恢复**：undo_pending按持久方向检查；已插入且可核验的恢复图片可以继续删除替换图；宿主已完成但回执失败时只补回执，不重复插图。未记录恢复对象ID时要求人工检查，不通过集合差异猜测所有权。
- **工作台与QA接线**：完整备份记录提供撤销，未决记录提供检查/可用的继续入口；展示原始摘要与恢复对象。写入均经提案确认，并只使目标页QA失效。

## 状态与边界

新记录主线pending→complete→undo_pending→undone。新图片替换在运行时要求附件/图片服务可用；旧记录没有备份时只保留其原有读取和正向恢复能力，不补造可撤销证据。复用的低层skill接口仍允许未配置备份的既有调用，但该路径不承诺持久撤销；产品运行时始终配置备份接口。

仅覆盖已有稳定导入映射的生成/生产页、原有受支持普通原生图片子集；裁剪/复杂效果/组合/链接图片仍按原有保守规则拒绝。原图每张<=2MiB；单条记录<=16KiB、图片记录<=32条且总计<=128KiB，包含未来撤销字段预留，因此复杂快照可能更早达到预算。原图与其它附件共享每文档32个/100MiB配额，复用同摘要已有附件。无新增依赖，未增加自动删除或配额回收。

无法连接PC、旧PC不支持原始附件读取、备份丢失/损坏、手工改图、页面/文档/任务切换均不能绕过校验。原始附件端点按文档隔离，仅返回ready图片的有限分块；校验完整原文件摘要和大小，拒绝符号链接。

不提供原shapeId复用、图片视觉diff、跨类型多级历史、任意现稿DeckBaseline或完整ChangeSet。修改前后快照用于一致性保护，不能当作真实视觉QA通过。旧版不能识别新增撤销状态，降级时保留备份和设置数据，不承诺旧版能恢复新未决事务。
