# PPT Agent：页生产成果导入与恢复

日期：2026-09-23。基线 `f65f21db`，分支 `codex/ppt-agent-implementation`。

## 1. 目标与状态

依据原方案§4.7、§5阶段E、§8.7、§11.6、O3、§14、§20/21，将上一批PC单页PPTX成果接入宿主逐页追加、回执及页面编号回读。O3、总体阶段3和P0仍为**进行中**；原方案继续作为验收权威。

## 2. 完成项

- 新增导入准备工具：严格读取指定任务，全部编译完成后按计划顺序获取各页产物，核验文档、项目、请求、页ID和计划版本；总解码上限10MiB。完整集合原子发布，仅缓存最近成功准备的任务。
- 独立生产导入与读取导入状态工具，复用既有一次确认、逐页写入、ID回读、断点恢复机制；原文稿页面保留。
- 新增v2回执及业务pageIds，支持每份单页PPTX的sourceSlideId相同；实际Office选页始终传文件内真实编号。摘要绑定完整有序集合、版本与身份。
- 生产回执使用production/project/request独立命名空间，避免与整稿编译同名请求互相覆盖。先保存inFlight，再写宿主，回读后保存完成；不确定写入不自动重放。
- Taskpane导入卡区分页生产任务，显示已记录页数和恢复状态。该任务激活时隐藏旧整稿QA卡并阻断旧QA/编辑绑定，防止误操作另一份产物；显式恢复或导入旧成果后可切回。

## 4. 未完成与偏差

- 当前需全任务编译完成后准备并导入，尚无边编译边写入、失败页绕过后的宿主顺序协调或实时业务事件重放。
- 回读只检查页面ID、数量和顺序，不是内容、渲染、来源或保存重开验收。该页生产任务尚未接入逐页QA与稳定编辑工具；下一阶段补齐映射。
- 不替换或删除现有页面；首批单页重做与撤销仍未完成。没有拼接单页OOXML或新增完整整稿下载。
- 20项真实材料包、真实Office任务执行与RoundTrip均待完成；不报告未经测量的完成率。

## 5. 风险变化

降低成功页重复写入和重复文件内编号导致误绑定的风险。准备失败保留旧有效缓存，重新准备成功会使旧提案过期；并发准备采用最近启动的有效准备任务优先。取消发生在宿主提交之后仍需回读并保存结果；若无法确认则保持inFlight，不删除或重放。

仍沿用每文档32条导入记录及100000字符限额；容量不足或保存失败会阻止继续。成功ID回读不证明所有原生对象、备注及样式在实机中保真。
