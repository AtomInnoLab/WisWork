# PPT Agent：现稿基线与选区上下文

日期：2026-09-24。基线 b3ce6586；隔离分支 codex/ppt-agent-implementation。按原方案 §6.1、O5 推进，原方案不变，实机验收继续暂缓。

## 本批完成

1. **独立于生成流程的现稿读取**：直接使用宿主页 ID 和对象 ID，读取页序、当前页、选中页/对象、类型、几何信息、普通文本和文字占位符、聚合字体名称/字号/颜色、母版与版式 ID。可用时读取尺寸、母版样式和主题色。
2. **明确作用范围**：支持当前页、选区、整套三种范围。选区有对象时指向当前页选中对象；没有对象时指向选中页。空选区拒绝，不退回第一页。读取页内其它对象作为上下文，不扩大目标范围。
3. **基线与变化检查**：双次读取范围内内容，检查期间页序/选区和文档身份，稳定后保留会话基线及 SHA-256 内容摘要。检查工具报告已读取页面字段、页序、选区、尺寸、母版样式是否变化，不静默替换旧基线；不按页索引重定向已删除页。
4. **按基线页 ID 获取截图**：复用现有宿主截图和 PNG 验证；校验返回页 ID、对象几何和尺寸，截图前后重新读取基线。图片供模型和界面使用，不把截图视为 QA 通过。
5. **离线与会话隔离**：工具注册为本地 PowerPoint 扩展，不要求生成成果、导入回执或 PC 在线；清会话销毁基线，取消或被新请求取代的迟到读取不会提交结果。其它 Office 宿主不增加这些工具。

新增工具：`read_presentation_baseline`、`check_presentation_baseline`、`read_presentation_baseline_page`。

## 边界与原方案缺口

- 本批是**现稿只读基线**，尚未把任意现稿接入持久修改保存点、撤销、QA 和项目恢复。基线仅保留会话内最近一份，清会话后须重新读取。
- 双读不是宿主原子快照。SHA-256 仅覆盖已读取字段；图片字节、图表/表格/组合内部、完整富文本样式和全部外观未覆盖。`unchanged` 只表示已读取字段未发现变化，不能授权写入。
- 备注、已有来源明确 `not_read`；字体为对象级聚合值，混合值保留 null；不表示读取了所有文字 run。截图按需读取；没有隐式视觉验收。
- 整套范围最多20页，上下文最多500个页 ID，每页100个对象；单对象文字最多12,000字符、单页文字120,000字符，基线完整 JSON 最多256KiB。超限明确拒绝，不截断后声称完整。大型文稿可先读取当前页或选中页。
- 读取使用已有文档身份绑定；首次建立身份可能保存 Office settings 元数据，不修改幻灯片内容。没有新增持久业务 schema、依赖、后台迁移或用户数据删除。
- 对象选区已覆盖；文字字符级选区、完整多操作 ChangeSet、低风险自动执行尚未实现。

原生选区要求 PowerPointApi 1.5；文字/图片占位符使用1.10的nullable TextFrame安全区分，较低版本遇到占位符明确拒绝整页读取，避免返回遗漏标题正文的基线；可选尺寸、母版高级属性和截图复用现有1.10能力，不支持时明确缺失或拒绝对应操作。参考[微软 Presentation API 文档](https://learn.microsoft.com/en-us/javascript/api/powerpoint/powerpoint.presentation?view=powerpoint-js-1.5)及[1.5 requirement set](https://learn.microsoft.com/en-us/javascript/api/requirement-sets/powerpoint/powerpoint-api-1-5-requirement-set)，并核对仓库内 office-js 类型定义。
