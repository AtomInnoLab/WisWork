# PPT Agent：来源权威性、时效与适用范围复核

日期：2026-09-29。依据原方案的证据链、关键来源检查和交付问题账本，继续在既有 Office 插件、PC 与冻结生产记录中实现。

## 本轮完成

- 增加可选来源评估：范围、权威性及来源等级、时效判断及参考日期、原主张/来源时点、适用范围、理由和原文依据。评估沿用不可变主张复核存储，不增加独立账本或外部服务。
- 插件必须先读实际原文窗口；依据采用绝对 UTF-16 位置并逐字匹配。PC 重建实际证据摘要，再核对冻结主张和来源标签；不存在的时点和适用范围不能猜测补填。正向判断需要原文依据；缺乏依据可以保存明确的不确定判断。
- 完整评估进入摘要、持久记录及重开读取。同 ID 相同重试复用原记录，改变评估拒绝；回复遗漏评估不能被插件认作成功。原文控制符保留，解释字段严格校验；旧单记录 8KiB、新评估记录 24KiB，总 256KiB、32 条限制保持。
- 报告增加权威性、时效、适用范围的 13 类问题，每主张/来源每维最多一个；保留所有历史判断，比较等级、结论及参考框架，不能让最新记录覆盖旧判断。不同参考日期不自动认作事实矛盾。
- 问题摘要覆盖对应完整评估、冻结主张/来源与研究上下文；新增判断改变摘要后，旧处置过期并恢复待处理。supported 原文支持或 explained 处置不能关闭研究冲突。
- 界面中文显示来源问题，默认折叠完整历史理由、窗口、日期、等级、范围和原文；正向无问题的评估也可查看。交付 ZIP 的 JSON/Markdown 保留真实持久评估及未解决研究问题。

评估始终是有明确范围的历史 Agent 意见，`sourceAuthority`、`timeliness` 仍为 `not_verified`，不能据此认证真实出版方、法规现行性或专业事实正确性。旧无绑定、无评估报告保持原形状和摘要；绑定/有评估页的问题容量扩为 1056，报告 8MiB 和原文窗口 8000 单元保持。
