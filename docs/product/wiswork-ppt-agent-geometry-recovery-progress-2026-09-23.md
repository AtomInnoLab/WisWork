# PPT Agent：不确定几何保存点检查与恢复

日期：2026-09-23。基线`48d6d76c`，分支`codex/ppt-agent-implementation`。

## 1. 目标与状态

依据原方案§6.4、§8.7、§11.8、§14、§20/21，为上批pending/undo_pending保存点提供检查及确认恢复入口。几何恢复这一局部能力完成后，完整撤销、单页重做及P0仍为**进行中**。

## 2. 完成项

- 新增几何保存点检查工具：读取同一文档、任务、业务页和对象的当前几何，以0.01pt容差比较原值与目标值，返回已达到目标、可继续写入或需人工核对。
- 对pending修改与undo_pending撤销使用同一规则，方向取自日志状态；同时匹配两端或均不匹配时不自动选择。
- 新增确认恢复工具：只有当前值已是目标值时补齐回执而不重写对象；仍为原值时在确认后写入目标值并回读。使用已有pending日志，不引入新状态。
- 提案绑定完整日志与精确观测几何，确认后分支或数值变化会失效；保存失败保持不确定状态，重试需要重新读取与确认。
- 恢复复用现有QA写入互斥和目标页局部失效，保持文档与来源隔离。

## 3. 验证证据

- 全仓 `npm test` 通过：6,058项Vitest测试，其中Office插件855项；既有脚本与原生测试通过。
- 全仓 `npm run typecheck`、变更代码ESLint、`git diff --check`通过。
- 测试结束后Office插件和Shell生产构建通过；插件仍有大于500kB分包提示。
- 独立复审无剩余重要问题；审阅方运行页编辑与跨runtime两个文件50项测试通过。
- 新增保存失败跨重开回归先因工具未接入失败，接通后通过。覆盖pending与undo_pending两种方向、两条恢复路径、模糊状态、精确观测漂移、取消、文档切换、CAS失败及重复恢复。
- 复审发现inspect/resume工具说明误用了撤销描述，已分别修正并增加工具说明回归。

跨runtime测试使用真实Office设置绑定、模拟宿主几何适配器与服务响应：注入修改生效后applied保存失败、撤销生效后undone保存失败，重建runtime并恢复同一生产任务，检查当前值后确认仅补回执，断言宿主写入次数不增加、最终状态正确、QA只涉及目标页。真实PowerPoint未执行。

## 4. 未完成与边界

- 当前几何匹配仅说明观测值与保存点一致，不证明历史原操作确实导致该值；工具输出不作因果断言。
- 混合值、手动改动、模糊容差、对象缺失或身份/摘要变化会停止；没有自动强制回滚或丢弃日志入口。
- 仍仅覆盖位置和尺寸；文字富文本、图片对象、整页替换及通用ChangeSet撤销未完成。
- 单页重做、内容证据QA、真实RoundTrip、20项专业材料及实机验收仍待完成。工程测试不能替代P0交付率。

## 5. 风险变化

消除部分保存失败导致几何修改永久不可继续的阻塞，同时保留明确确认与精确观测基线，防止将不确定写入盲目重放。已达到目标的恢复仍会使目标页QA待复检，因为回执补记不等于质量验收。

恢复期间发生用户改动依赖写前读取及adapter预期值比较发现；没有跨客户端全局事务。手工恢复到相同值无法判断来源，确认界面只展示当前观测。
