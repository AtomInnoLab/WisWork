# PPT Agent 图表数值修改保存点阶段进展（2026-09-24）

## 本阶段完成

- 图表数值修改在宿主写入前，将原始单页 PPTX（最多 8 MiB）经已配对的 Relay 发送到本机 WisWork PC 既有的 `userDataPath/presentation-existing-page-backups`。该路径和数据范围已获用户明确允许。PC 端按文档和备份 ID 隔离，分块写入并核验 SHA-256。
- 文档设置中新增受校验的图表变更记录，保存写前包摘要、写后包摘要、原页和新页 ID、备份元数据及执行状态；变更历史和工作台可显示、检查、恢复和撤销。
- 写前持久化意图，宿主替换后记录新页 ID；撤销仅在当前页仍匹配写后包时，从备份读取原包并提出确认。中断恢复按当前包内容判定状态，不重复执行未知结果的宿主写入。
- 在 PowerPoint 适配器内部再次核对当前页 ID 与完整包摘要，减少外层校验与实际替换之间覆盖手工修改的窗口。该检查受 Office.js 非原子事务能力限制，不能宣称严格的比较写入保证。

## 边界和下一步

- 本阶段通过自动化和模拟宿主测试验证逻辑。真实 PowerPoint 保存、重开、原生可编辑性、视觉截图和撤销验收仍按用户要求暂缓，当前 **0/20**。
- 既有 PC 备份服务目前每个文档最多保存 8 份备份；额度用尽时新修改会在宿主写入前失败。下一阶段需要增加可核验的保留和清理策略。
- 下一步以真实宿主运行这组验收；根据发现修复 Office 导入可能导致的包规范化、页面 ID 和视觉差异，并继续扩大复杂图表覆盖范围。
