# PPT Agent 图表数据源核验阶段进展（2026-09-24）

## 本阶段完成

- 在现稿基线中新增只读 `read_presentation_baseline_chart_source`：按幻灯片和原生图表形状 ID 精确定位，导出前后检查基线漂移和页面顺序，不赋予写入或 QA 通过状态。
- 解析单个图表的序列缓存和来源关系：区分嵌入式 XLSX、外部链接、仅缓存；外部链接不发起网络请求。对受支持的 `Sheet1` 连续单元格区域，读取嵌入工作簿并与缓存逐点比对，返回匹配、不匹配或无法核验，以及工作簿摘要。
- 为现有 `edit_slide_chart` 的图表 XML 替换加入数据保护：标题等展示内容仍可改动；序列、缓存、公式和来源链接改变时拒绝。独立复审指出的替代命名空间前缀绕过、缓存 `ptCount` 漏检均已修正并补测试。

## 边界和下一步

- 当前只提供图表数据源证据；没有实现对嵌入工作簿和图表缓存的同步写入。`matches` 只表示两份包内数据一致，不代表数值真实或图表完成验收。
- 下一步按原方案推进有界的图表数据更新：先定义可安全写入的嵌入工作簿范围和来源关系，再实现工作簿与缓存同步修改、保存点、回读和撤销。无法证明一致性的图表保持只读。
- 真实 PowerPoint 时机验收按用户要求暂缓，目前 **0/20**。
