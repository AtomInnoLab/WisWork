# O1/O2：真实网络图片与网页资料获取历史

日期：2026-09-29。依据原方案 §4.3、§4.6、§5.B/E、§7.1 和 O1/O2。原方案及退出门槛不变。

## 完成范围

1. 网络图片和网页原文的实际获取链路，在校验请求后保存开始；图片下载/转码、网页抓取/正文解析或已验证的本机缓存复用成功后，保存结果和精确附件摘要。获取失败、超容量、解析失败、来源冲突、动画暂存或取消保存安全失败。
2. 文档级历史独立存储，包含真实尝试身份、来源摘要、开始/结果时间、产物身份和安全错误。最近 64 条窗口保留连续尝试编号及累计计数；校验和、原子写、文件同步、有界读取和符号链接拒绝，重开恢复原记录。结果重放不改原结束时间，冲突拒绝。获取记录时间是操作时间，缓存复用不意味着来源被重新抓取或更新，源资料的原始 retrievedAt 保持原值。
3. 历史读取绕过网络获取的文档锁，能够在实际下载未结束时读到开始记录。只读查询不恢复或重放网络动作；没有结束记录时不推断后台仍在运行。
4. PC 增加独立可选读取操作，旧附件、页任务及图片获取回执保持兼容；修正网页获取错误被误报为编译失败的既有分类问题。获取历史损坏不删除附件，结果历史写失败保留已发布产物和未决开始记录。
5. 实际 Office AttachmentSkill、HostRuntime 与工作台接通读取，严格核对文档和字段；取消、清会话、文档切换及迟到结果隔离。旧 PC 不支持时隐藏历史入口。
6. Taskpane 资料区默认折叠网络获取历史，按素材类型与完整来源 URL 摘要归并，同一来源不同查询版本不误合并；显示最新状态并保留每次尝试、时间和中文原因。产物 ID 放在折叠技术详情。获取成功或失败后刷新，保留已上传资料。

URL 查询参数、片段、认证凭据和原始异常不进入公开历史。获取成功只表示本机受控产物可用，不代表来源真实性、版权/许可、品牌、页面编译或视觉 QA。

## 验证

先复现新增 Store、实际插件读取入口、React 展示与跨层恢复缺失，再实现。真实 PC 服务到实际 Office AttachmentSkill 的五项跨层测试通过：

- 备用图片源先失败后成功，重开 PC/Taskpane 恢复两次原记录，再明确获取时命中缓存不再次下载。
- 网页失败后用户明确重试，保存原始 HTML 摘要、字节长度和正文产物身份。
- PC 已保存结果但客户端响应丢失时，只读恢复 ready，网络请求仍只有一次。
- 网络请求待完成时并发读取 fetching；不构造结束时间，随后真实完成变为 ready。
- 清除任务窗格后取消在途下载，重开恢复安全中断；不自动重放、不泄露原始异常或 URL 查询。
