# 项目保留期、删除事务与审计基础：阶段记录

2026-09-29。依据原方案 §13.1 及项目存储核对计划。本轮完成基础存储、真实资源预览、后台栅栏接口和四项 PC 元数据 API；尚未完成统一删除执行器、定时到期清理和全部写入口接线。

## 完成内容

- 独立生命周期控制目录，核对已有项目/文档归属；持久版本 CAS、active/deleting/deleted 状态、删除意图与逐资源回执，损坏或归属不明时拒绝重置。
- 默认内容和审计保留期为 null，明确保存到用户配置。策略可通过实际 PC 服务初始化、读取和更新；匿名审计可导出，不包含正文、附件、路径、URL、完整项目/文档 ID 或原异常。策略存储不表示到期清理已运行。
- 删除事务只有全部资源已移除或解除引用才能闭合为 deleted；保留项、失败或未决均不冒充完成。开始及每次非终态结果为后续成功回执和最终闭合保留事件/字节额度；政策更新亦为最小删除保留空间。大清单和更多重试仍受明确配额限制。
- 只读预览实际项目、研究、交付包、原页、偏好、评论、观察、团队和共享命名空间。项目独占仅列候选；文档共享原包、母版/XML 备份、未知暂存和全局品牌引用保留。公开清单没有路径或正文，候选仍须实际执行前冻结、停止 worker 并重新核对。
- 预览兼容原有 17 MiB 项目记录、64 MiB 研究记录及两套各 4096 个 blob 的命名空间；不缩小旧存储容量。叶文件和父目录替换、symlink、越界及预算超限拒绝。
- 后台生产和资产事件可注入同步写入栅栏；每次写、失败结果、页面回调和 job 事件均核对。按项目/文档停止并等待实际 worker 结束，不持项目锁等待。暂停仍允许当前页完成，取消保留最后已知回执，显式恢复可重编译。

## 生产入口后续接线

源码 `aae268bf` 保存初始固定写租约，`e27f0bd4` 接通已有项目 `production_*` 的实际写入栅栏及纯读兼容。首次受理固定文档、项目、请求和生命周期原版本，等待锁与异步返回后复核；后台不继承受理请求取消信号，页面、资产、失败与 job 回执、交付问题动作的实际落盘均使用原版本。只读操作不初始化旧项目的控制文件；缺控制记录时固定“仍不存在”，其后出现任意控制记录均拒绝旧结果，并不续租。纯读检查不授予写权限。
