# PPT Agent：本机项目内容保留期执行阶段

日期：2026-09-30。依据原方案 §13.1 与 `docs/superpowers/plans/2026-09-30-ppt-project-retention-execution.md`。工程验证仅使用临时合成目录；未部署、未对真实项目运行到期扫描。

## 已实现

1. 项目库存可选返回内部活动证据；同时观察七类已证明独占的正文命名空间及文件/目录 mtime、ctime、创建时间，把最近一次明确保存的策略时间作为基线。默认预览返回结构不变；无归属、共享、异常时间、替换或超预算均不具备自动删除资格。独立复审发现并修复动态 getter 丢失策略时间的问题。
2. 只读观察真实前台与后台项目工作。到期执行在现有项目锁内固定生命周期版本、策略时间和活动证明，复核实际 Store 绑定、全量库存及无在途工作，然后通过既有执行器持久开始 `reason:'retention'` 的删除意图；冻结后沿用真实 drain、逐资源回执、部分失败与同意图恢复。外部七操作不接受或暴露 retention 理由。
3. PC 端扫描实际生命周期控制目录，读取上限为 2 MiB 且用定长读取和元数据复核；只把控制中的项目 ID 作为候选，删除前仍由真实 Store、控制记录与库存二次证明。一次 `tick()` 可用注入时钟手动验证。双实例同时扫描最多启动一个删除意图；旧的删除中意图只按原 `deletionId` 恢复。
4. 自动执行仅在 PC 同时设置 `WISWORK_PPT_PROJECT_GOVERNANCE_ENABLED=1` 和 `WISWORK_PPT_RETENTION_AUTOMATION_ENABLED=1` 后运行；启动时执行一次，之后每 24 小时运行一次，退出时取消定时器。默认两个开关均不启用。Office 构建开关 `VITE_WISWORK_PPT_PROJECT_GOVERNANCE_ENABLED=1` 仍仅控制界面显示，不代替 PC 开关；界面文案已说明默认不开自动清理。
