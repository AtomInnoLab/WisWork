## 对应方案与本轮交付

按原方案 §6.4 与 O4，验证修改后的截图、目标页回读和局部复核衔接。复用现有 QA 工具和事务状态，不新增持久化格式或依赖，不改原方案。

本轮修复：QA 工具与页面状态展示共用有效成果检查。`commit_pending`、`undo_pending`、`restore_inserted` 或旧成果已被取代时，不再访问旧宿主页，也不能读取该成果的 QA 或记录视觉通过；返回现有 `presentation_restore_required`。先用原提交/撤销工具完成恢复，再显式 prepare 当前成果。

扩展既有跨层测试，验证完整过程：

1. 父任务目标页截图并复核，另一个页面保留独立记录。
2. 暂存使目标页待复查，非目标记录不变。
3. 提交后最终回执保存失败，所有 QA 入口在宿主读取前停止；恢复提交后，旧缓存仍不可用于 QA。
4. prepare 子任务后，截图和结构回读指向修订页稳定 ID，可只复核该页，不要求其它页先通过。
5. 撤销删除修订页后状态保存失败，同样阻止 QA；修订页记录标记待复查。
6. 恢复撤销并 prepare 父任务后，旧截图不能直接复核；重新采集恢复页稳定 ID 后可记录视觉复核。非目标父页历史记录保持不变。
