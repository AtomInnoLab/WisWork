# PPT Agent：生产页QA与稳定编辑绑定

日期：2026-09-23。基线 `c1c5a5dc`，分支 `codex/ppt-agent-implementation`。

## 1. 目标与状态

依据原方案§5阶段F、§6.4、§8.9、O3/O4、§11.8、§20/21，将生产页v2回执接入已有截图、结构QA、视觉评审和稳定编辑能力。O3/O4及P0仍为**进行中**，原方案继续作为开发和验收权威。

## 2. 完成项

- 统一产物摘要输入及业务页映射，保留v1整稿原摘要和v2页集合原摘要。生产页按pageIds索引对应已确认的宿主页，支持各文件sourceSlideId重复；不确定页和未完成页拒绝QA/编辑。
- 生产任务接入截图、结构检查及Agent视觉复核。QA记录与截图文件隔离文稿、任务及来源，避免与旧整稿同名记录混用；历史记录不代表当前页面状态。
- 生产页接入既有稳定文字、几何、普通图片替换与图片恢复路径。图片日志增加可选生产来源，键值隔离且来源不可变；旧记录摘要保持兼容。
- Taskpane按显式选中的产物提供QA和编辑，不自动回退另一来源。重新准备或切换任务后旧提案失效；QA卡明确展示页生产来源。
- 修改后按真实宿主页ID使QA失效，无关页保留；所有异步边界检查文档、产物、回执和内容的新鲜度。

## 3. 验证证据

- 全仓 `npm test` 通过：6,030项Vitest测试，其中Office插件827项、Shell328项；既有脚本及原生测试通过。
- 全仓 `npm run typecheck`、全部变更代码ESLint、`git diff --check`通过。
- 测试结束后Office插件与Shell生产构建通过；插件仍有大于500kB分包提示。
- 共享摘要/定位与旧导入定向18项、稳定编辑定向30项、QA/文档绑定定向47项、Shell跨层文件10项通过。共享helper与runtime接线新增回归先失败后通过。
- 独立代码及测试审阅未发现新增P1/P2问题；审阅与上述实际测试执行证据分开记录。

跨层测试沿用真实PptxGenJS生成8份单页产物、PC服务、插件准备、浏览器导入适配器与模拟Office宿主。导入3页后中止、重建续写5页，再通过模拟页面检查/文字适配器验证前2页QA、第二页编辑只使第二页待复检、切换整稿后旧提案不能写入。真实Office未运行。

## 4. 未完成与偏差

- 当前复用的是结构/截图检查与Agent视觉判断；内容/来源核验、数值复算、专业证据审核、真实保存重开RoundTrip仍未完成。
- 未实现单页重做或撤销最近变更集，它们继续属于首批缺口。没有实现完整现稿基线或任意现稿编辑。
- 页面生产仍先完成编译再导入；边编译边写入、统一业务事件重放和跨任务依赖页重编译待后续。
- 20项真实材料包及实机验收尚未完成，未测量P0任务通过率。工程测试和模拟宿主不能替代该证据。

## 5. 风险变化

消除重复文件内页面编号导致QA/编辑误定位的风险，并隔离旧整稿与生产任务同名记录。沿用既有确认、新鲜度检查、图片恢复不确定状态和局部QA失效规则；截图本身不自动代表视觉通过。

QA和图片记录依旧受既有条数/容量上限约束，没有新增配额豁免。添加来源字段后的文档在旧客户端可能被拒绝读取，回滚不能删除记录绕过限制。
