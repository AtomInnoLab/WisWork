## 实施范围

- 保留 `edit_slide_master_xml`、version 1 声明式 `replace_xml`、1–32 唯一路径和原程序/包预算；Mac 母版 XML 排除规则保留。
- 独立 `master_xml` 紧凑文档账本；PC 复用 `presentation-package-backups.v1`，持久保存原包、准备包、全页顺序/摘要、原生依赖和阶段证明。全量原页逐页流式备份，不在内存保留 600 个大包。
- SDK 分离插入、布局应用、导出证明和删除阶段；每次写前保存 intent，记录实际页/母版/布局身份。未知 ACK 通过只读观察及显式核对解决，不自动重放或异常逆写。
- 布局代表包不足时，使用已备份事务内的独立探测副本；每次探测和删除均有回执，不把布局探测直接应用到正式原页。
- 回读证明同时保护正文、备注、图表、工作簿、图片、外部关系叶及未引用部件。关系图可证明的路径重编号保留支持，无法证明的孤立部件保持精确路径身份。
- 逐受影响母版派生独立 carrier 并导入、记录实际三 ID；以只导入所选 source 母版的夹具验证，覆盖次级母版和共享主题。正式写入前保存并读验当前原始页面包；同一 raw SHA 可复用已持久引用，仍每次重新读取 PC 字节和当前宿主状态。
- 原包恢复核对完整顺序、所有受影响原生布局关联和实际还原页 ID。未证明的布局写入必须先显式核对为 `recovery_required`，再确认原包恢复。
- 文档设置/CAS、统一历史、工作台动作、有限本地检查点确认、完整影响页 QA 范围及 ACP 活动接入。历史截图复核不认证当前页面或整个文档。

## 独立审查修复

准备、原包探测、已导入与导入布局探测的已知检查点，在尚无正式页面写入时提供继续/丢弃；未决阶段仅检查/核对。工作台不提供该阶段不可用的撤销。恢复工具仅输出有限错误码，未知传输或 SDK 异常统一为 `presentation_master_xml_failed`，不原样输出底层文本。两项均有先失败后通过的回归和独立增量复核。

## 压力测试内存核对

最终综合运行出现 4 GiB 堆耗尽，不能记作通过。12 页实测中，测试 spy 在完整修改/撤销后保留 1551 个 PC Promise/Response 和 256 个全页快照；仅这些快照 JSON 约 1.02 MiB，随页数及步骤数共同增长。压力夹具现直接调用同一实际实现，只保留布局写入目标 ID 计数，不保存完整调用参数/返回对象历史；生产算法、所有宿主证明读取、PC 存取及原 600 页断言没有减少，未增加堆或超时预算。

小范围完整修改/撤销新增回归先失败后通过，独立再次通过；断言 request 及所有 adapter spy 历史均为空，业务写入计数仍正确。600 页默认堆压力测试正在独立重跑，必须取得最终终态才能闭合此项。

## 明确边界

`Slide.applyLayout` 使用实际原生身份；不以名称、序号或包内 ID 猜测映射。布局探测不能证明其 API 在所有宿主的实际行为。宿主没有可用于此流程的可靠母版删除接口，本批记录引入的母版数量，并保留 `inventoryCleanupVerified: false`；不宣称恢复了完整母版库存。

每次宿主写仍核对完整宿主顺序、摘要和依赖。原备份在准备、首次宿主写前、撤销开始和最终闭合时全量读验；各步骤读取其所需原包及映射代表，不声称每个步骤重新读取全部原包。不可变证明链可缓存已经校验的 ancestry 哈希；当前证明与宿主状态仍重新读取，不缓存原始包字节。
